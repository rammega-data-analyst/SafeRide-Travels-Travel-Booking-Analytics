# SafeRide Travels – Travel Booking Analytics

## Project Overview
This Power BI project focuses on analyzing travel booking data to understand booking patterns and travel business performance through an interactive dashboard.

## Project Objectives
- Analyze travel booking information.
- Understand booking trends and patterns.
- Present key insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Power BI
- Data Cleaning
- Data Visualization
- KPI Reporting

## Data Cleaning
- Reviewed and cleaned the travel booking dataset.
- Prepared the dataset for analysis.
- Final cleaned dataset contains 2,504 records.
